# 📊 Adidas US Sales Dashboard

## 📌 Project Overview
This project is an interactive sales dashboard built in Microsoft Excel to analyze Adidas US sales data. It provides insights into sales performance, profit, products, retailers, and regional trends using Pivot Tables, Pivot Charts, Slicers, and Conditional Formatting.

---

## 🎯 Objectives
- Analyze total sales and profit
- Compare regional performance
- Track product-wise sales
- Monitor retailer performance
- Create an interactive dashboard for business decision-making

---

## 🛠 Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

---

## 📈 Dashboard Features
- Interactive Filters (Slicers)
- Sales Analysis
- Profit Analysis
- Product Performance
- Regional Analysis
- Retailer Analysis
- Clean Dashboard Design

---

## 📂 Dataset
The dataset contains Adidas US sales information including:
- Retailer

- Units Sold

- Total Sales
